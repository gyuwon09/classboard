# 클래스보드 AI

교사의 설명과 교재 내용을 글·수식·시각 자료로 자동 판서하여, 판서 시간을 줄이고 학생의 이해를 돕는 공교육 지원 웹 서비스입니다.

## 구현된 흐름

- 지구 탈출 속도 예제: NASA Apollo 17 실제 사진, KaTeX 분수·제곱근·약분 표시, 6단계 설명과 이전 수식 누적 표시.
- 읽을 시간 보장: 기본 수동 진행. 자동 진행은 20~60초 간격이며 일시정지·이전 단계 이동·탭 이탈 시 정지를 지원합니다.
- 내 자료로 판서: 텍스트 PDF 또는 직접 입력 자료 → 설명 입력/최대 30초 녹음 → 음성 인식 → 근거에 맞는 판서 제안 → 교사 확인 → 판서 표시.
- 교사 제어: 판서를 추가해도 읽고 있던 화면을 유지합니다. 다음 판서 이동, 전체 화면, 설명·수식 수정, 생성 즉시 중지, 마지막 판서 취소·복원을 지원합니다.
- 복습: 예제 6단계 또는 확인한 실시간 판서를 이미지 기반 PDF로 저장합니다.

## 자료와 안전

AI는 등록 자료에서 원문 구간 ID를 선택합니다. 실제 페이지와 인용문은 프로그램이 원문에서 가져옵니다. 자료 밖 요청, 알려진 단위 충돌, 불완전하거나 잘못된 응답은 판서를 보류합니다. 근거 일치가 설명의 모든 의미를 자동 보증하지는 않으므로 교사의 확인을 거칩니다.

API 키는 서버에만 둡니다. 앱은 원본 음성을 저장하지 않으며 인식용 음성과 판서 생성에 필요한 자료는 OpenAI로 전송됩니다. PDF 원본은 브라우저에서 읽고 추출한 텍스트만 판서 요청에 사용합니다. 판서는 현재 탭 메모리에 있으므로 새로고침 전에 PDF로 저장하세요.

현재 범위는 자동 판서와 복습 PDF입니다. 스캔 PDF OCR, 학생 질의응답, QR 공유와 3일 후 삭제는 아직 구현하지 않았습니다. 예제 모드는 준비된 내용을 표시하고 실시간 모드만 AI를 호출합니다.

## 개발 실행

Node.js 22.13 이상에서 `npm ci`, `npm run dev`를 실행합니다. 로컬 `.env.local`에는 `.env.example`의 서버 변수만 설정합니다. 키를 공개 변수나 소스에 넣지 마세요. Sites 운영 환경에서는 동일한 키를 비밀 환경 변수로 설정합니다.

- `npm test`: 진행 속도, 물리 계산, 근거 검증, 안전한 응답 처리 검증.
- `npx tsc --noEmit --incremental false`: 타입 검사.
- `npm run build`: 배포 빌드.
- `node scripts/check-live-api.mjs`: 로컬 서버에서 정상·단위 충돌·자료 밖 실제 AI 요청 확인.
- `node scripts/check-upload-api.mjs`: 제공 PDF 추출 후 개념·에너지 식·공식 도출과 원문 인용 확인.

실제 AI 검증에는 설정된 API 사용량이 발생합니다. 로컬 개발용 로그인은 운영 빌드에 포함되지 않습니다.

## 5분 시연 순서

| 시간 | 보여줄 내용 |
| --- | --- |
| 0:00~0:30 | 판서로 설명·학생 확인 시간이 줄어드는 문제 소개. 효율 개선은 검증할 가설이며 사교육 감소를 입증했다고 주장하지 않습니다. |
| 0:30~2:20 | 예제 전체 화면: 실제 지구 사진 → 에너지 두 항 → 에너지 보존 → 질량 약분 → 제곱근 공식 → 11.2 km/s. 각 단계에서 멈춰 설명합니다. |
| 2:20~3:30 | 실시간 모드에 public/earth-worksheet.pdf 등록. “물체 질량 m을 약분하면 탈출 속도는 물체 질량과 무관합니다”를 입력하거나 녹음. 원문 확인 후 판서를 추가합니다. |
| 3:30~4:10 | “탈출 속도는 11.2 m/s입니다”로 단위 오류의 판서 보류를 보여줍니다. |
| 4:10~4:40 | 복습 PDF 다운로드와 수식·지구 사진 확인. |
| 4:40~5:00 | 기존 손판서와의 작성 시간·정확성·학생 이해도 비교 실험 계획 설명. |

네트워크 장애 때는 예제 모드로 전환하고 준비된 예제임을 알립니다. 교실 소음에서의 음성 인식률과 수업 시간 절감 효과는 별도 현장 검증이 필요합니다.
