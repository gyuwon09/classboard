# autoboard

교사의 설명과 교재 내용을 실시간 자막과 자동 판서로 연결하는 수업 지원 웹입니다.

## 화면 흐름

랜딩 → 수업 자료 선택 → 자동 판서 → 수업 종료 · 복습 PDF 다운로드

## 이전 수업과 AI 복습

- 수업 종료 시 자료·판서·인식 기록을 이 브라우저의 IndexedDB에 저장합니다. 랜딩 페이지의 ‘이전 수업’에서 이름으로 찾고 다시 열 수 있습니다.
- 판서 PDF는 수업 화면을 보존하며, ‘요약 정리 만들기’는 별도의 AI 요약을 생성합니다. 요약 PDF는 한글 A4 세로 문서로 여러 개념을 페이지에 나누어 배치합니다. 두 PDF 모두 이전 수업 화면에서도 다시 내려받을 수 있습니다.
- ‘AI에게 질문’은 선택한 수업의 자료·검토된 판서와 최근 20개 대화를 참고합니다. 근거는 서버가 실제 자료에서 연결하며, 발화 원문은 오인식 가능성이 있어 사실 근거로 사용하지 않습니다. 요약과 답변은 AI 생성물이므로 교재 근거와 함께 확인하세요.
- 요약과 채팅도 해당 수업에 저장됩니다. AI 실패 시 기존 기록과 질문을 유지하며 다시 요청할 수 있습니다. 저장 실패는 별도로 표시하고 저장 재시도를 제공합니다.
- 저장은 계정 클라우드 동기화가 아닙니다. 같은 브라우저·사이트 주소에서만 보이며, 사이트 데이터를 지우면 삭제됩니다. 이번 기능 추가 전에 종료하고 저장하지 않은 수업은 복구할 수 없습니다. 원본 음성·PDF 파일은 보관하지 않습니다.
- `/api/lesson/study`는 기존 인증·동일 출처 검사를 적용하며 API 키는 서버에만 둡니다. 요약·질문 시 수업 기록이 OpenAI로 전송됩니다. 현재 AI 복습 입력 범위는 자료·판서 180,000자, 발화 120,000자입니다.

- PDF(20쪽·10MB 이하)를 올리거나 자료를 직접 입력합니다. 별도 예제 화면 없이 자신의 자료로 시작합니다.
- PDF의 문자 매핑이 깨졌거나 스캔된 페이지는 이미지를 렌더링해 OCR로 다시 읽습니다. 자동 감지가 놓친 경우 ‘PDF를 이미지로 다시 읽기’로 전체를 재인식할 수 있습니다. 인식 중에는 진행 상태와 취소 버튼을 표시하고, 실패한 자료로는 수업을 시작하지 않습니다.
- 마이크를 켜면 음성을 인식하고 중간 결과를 실시간 자막으로 표시합니다.
- 문장이 끝나면 자료에 근거한 판서를 순서대로 생성해 즉시 표시합니다. 별도 제안 수락 과정은 없습니다.
- 판서는 설명 대상과 현상을 중심으로 그립니다. 비스듬히 던진 물체는 공·포물선 궤도·속도 방향을 그리고, 속도 성분을 설명하면 수평·연직 화살표를 함께 표시합니다. 다른 물체·장치·자연 현상은 AI가 제한된 도형과 좌표로 장면을 구성하고 앱이 SVG로 그립니다. 수식은 그림의 대상 이름에 섞지 않고 별도로 표시합니다. 아이콘 관계도는 추상 개념 비교에 사용합니다. 설명은 80자 이하 한 문장으로 요청하며 출처 원문과 이전 수식은 접어서 확인합니다. 그림은 축척 없는 설명용이며 포물선 템플릿은 공기저항 없이 같은 높이로 돌아오는 예입니다.
- 흰 칠판, 청록·주황·파랑 잉크, 분리된 자막 띠로 구성하며 PDF에도 같은 도식을 포함합니다. AI가 생성한 SVG 코드나 HTML은 실행하지 않습니다.
- 판서는 일반 창에서도 화면 대부분을 사용합니다. 이전 판서로 이동한 뒤에는 ‘최신 판서로’ 버튼으로 자동 따라가기를 재개합니다.
- 수업 도구에서 직접 입력, 판서 수정, 마지막 판서 취소·복원이 가능합니다. 전체 화면에서 도구를 열면 일반 화면으로 전환합니다.
- 수업 종료는 마지막 음성과 대기 중인 판서를 처리한 뒤 복습 화면으로 이동합니다. 여기에서 생성된 판서를 PDF로 저장합니다.

## 로컬 실행

### 이미지 읽기와 관련 주제 확장

PDF 페이지는 최대 3쪽씩 병렬 처리합니다. 각 페이지의 텍스트 추출·렌더링·OCR이 독립적으로 진행되며 최종 결과는 원래 페이지 순서로 정렬됩니다. 한 쪽이라도 실패하면 나머지 요청을 취소하고 부분 자료를 수업에 적용하지 않습니다. 진행률은 완료된 페이지 수입니다.

교재에 직접 없는 내용도 수업 주제와 관련되면 판서 초안을 만듭니다. 관련성을 별도 검토하고, 관련 확장으로 분류한 초안은 외부 교육·공공기관 자료로 사실을 검토합니다. 외부 근거만 있는 항목에는 교재 문장을 직접 근거로 표시하지 않습니다. 무관한 주제·틀린 설명·확인할 수 없는 내용은 계속 보류합니다.

Node.js 22.13 이상과 `.env.example`에 기재된 서버 환경 변수를 사용합니다. API 키는 `.env.local`에 설정합니다.

```powershell
cd C:\gyuwon\contest\elice\classboard
npm ci
node scripts/run-framework.mjs dev
```

의존성이 이미 설치되어 있으면 `npm ci`는 생략합니다. 기본 주소는 http://localhost:5173 입니다. 마이크는 Chrome/Edge의 localhost 또는 HTTPS에서 권한을 허용해야 합니다. 로컬 개발 인증은 localhost에서만 사용하며 운영 환경의 인증 검사는 유지됩니다.

## 음성과 판서 처리

마이크 → WebRTC 연결 → 음성 인식 중간 결과 자막 → 문장 확정 → 순차 판서 큐 → 판서 자동 표시.

실시간 인식은 `gpt-live-transcribe`를 사용합니다. 브라우저에서 약 0.9초의 침묵 또는 12초 연속 발화를 기준으로 음성을 확정합니다. 처리 결과가 늦게 도착해도 발화 순서를 유지하고 즉시 중지 후 도착한 응답은 표시하지 않습니다. 모델 사용 권한과 네트워크 상태가 필요하며 교실 소음에서의 인식률은 현장 검증이 필요합니다.

## 자료와 안전

판서는 다음 검토를 모두 통과한 뒤에만 표시합니다.

1. 인식 문장에서 교재와 문맥으로 확인되는 용어 오인식을 먼저 보정합니다. 원문·보정문·근거를 함께 보관하며 숫자·단위·방향·부정 표현은 임의로 바꾸지 않습니다. 보정 후에도 불명확한 개념은 보류합니다. 같은 제목의 재설명도 판서를 진행합니다.
2. 교재 근거와 별도 모델의 의미·사실 검토를 먼저 수행합니다. 교재가 뒷받침하는 통상적인 내용은 외부 검색 없이 통과할 수 있습니다. 불확실한 항목에만 교육 출판사·공공 과학기관으로 검색을 제한하여 외부 근거를 추가합니다. 이때 실제 검색 완료와 해당 항목의 출처 링크가 필요합니다.
3. 화살표 방향은 좌표 차이로 직접 계산합니다. 수평 바닥에 놓인 물체의 명시된 수직항력이 아래로 향하거나 교재의 아래쪽 중력이 위로 향하는 등, 조건이 명확한 오류는 코드가 우선 차단합니다. 경사면·천장·지면에 가하는 반작용에는 수평 바닥 규칙을 적용하지 않습니다. 이어서 별도 모델 호출로 인식 용어, 제목, 설명의 모든 주장, 수식·수치·조건, 개별 그림 요소와 전체 관계를 교재 및 외부 근거에 대조합니다. 실제 좌표로 계산한 방향과 템플릿의 궤도·가정도 전달합니다. 교재 인용은 서버가 제공한 원문 구간에서만 선택합니다.
4. 검토 누락·중복, 모순, 해결되지 않은 불확실성, 원문과 다른 인용, 검색 결과에 없는 URL은 보류합니다. 생성된 그림·수식의 검토 실패는 초안을 한 번만 자동 수정하여 재검토합니다. API 실패 시 미검증 초안을 표시하지 않으며 기존 판서는 유지합니다.

판서 하단의 ‘근거 검토 통과’에서 출처 링크와 항목별 교재 근거를 확인합니다. 설명이나 수식을 수정할 때도 `/api/board/verify`로 다시 검토한 뒤 반영합니다. 검증 정보가 없는 이전 판서나 내용이 바뀐 판서는 그림과 수식을 표시하지 않습니다. 새 수업에서 다시 생성해 주세요.

검토는 의미와 방향을 모델이 판단하므로 **수학적 증명이나 사실의 완전한 보증이 아닙니다**. 외부 확인이 필요한 내용에 신뢰할 출처가 없으면 보류됩니다. 구조화된 그림 데이터와 렌더러의 관계 규칙을 검토하며, 교사는 근거 확인·즉시 중지·수정을 사용할 수 있습니다.

검증 모델은 `OPENAI_VERIFICATION_MODEL`(기본 `gpt-4.1`)로 지정합니다. Responses API의 `web_search`와 구조화 출력을 지원해야 합니다. 기본 흐름은 초안 생성과 독립 검토 2회이며, 불확실성이나 초안 오류가 있으면 검색·재검토 또는 1회 수정이 추가됩니다. 전체 요청 제한은 90초입니다. 미검증 초안을 검증 성공으로 재사용하지 않습니다. 외부 검색에는 일반 개념을 사용하며 지정 기관 도메인으로 제한합니다.

API 키는 서버에만 둡니다. 음성과 추출한 수업 자료는 OpenAI로 전송됩니다. PDF 원본은 브라우저에서 읽으며, OCR이 필요한 경우 해당 페이지 이미지를 OpenAI로 전송합니다. OCR에는 기본적으로 gpt-4.1을 사용하며 서버의 OPENAI_OCR_MODEL로 변경할 수 있습니다. [이미지 입력 공식 문서](https://developers.openai.com/api/docs/guides/images-vision)를 따릅니다. 불명확한 글자·수식은 원문과 비교해 수정하세요. 앱은 원본 음성을 저장하지 않습니다. 진행 중인 수업은 탭 메모리에 있고, 수업 종료 시 판서와 인식 기록을 이 브라우저에 저장합니다. 중요한 자료는 PDF로도 보관하세요. PDF는 화면 모양을 유지하는 이미지 형식입니다.

이전 수업의 AI 질의응답을 지원하며 QR 공유는 현재 범위에 포함하지 않습니다. 기존 지구 관련 파일은 개발용 자료로만 남아 있으며 별도 예제 화면은 제공하지 않습니다.
